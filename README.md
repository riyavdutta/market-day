# Market Day

A small, cozy game set at a hill market. You mind Riya's stall for a day, choose what the chalkboard sign says, and watch five villagers (Pip, Juno, Nell, Kiko and Wren) decide whether to buy. At dusk the ledger shows who bought what, and why.

Each villager responds to a different nudge: the decoy effect, scarcity, social proof, anchoring and where something comes from. You can change the sign once at lunch, and a perfect day takes the right sign at the right time.

## Run it

It's one HTML file with no build step. Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```
